# API 接口文档

## 概述

Blaze Query 项目提供了一系列 RESTful API 接口，用于支持电商平台秒杀商品相关的各种功能。本文档详细描述了这些 API 的使用方法、请求参数、返回结果以及错误处理等信息。

## API 规范

所有 API 接口遵循 RESTful 设计原则：
- 使用标准 HTTP 方法（GET、POST、PUT、DELETE）
- 使用合适的 HTTP 状态码表示请求结果
- 使用 JSON 格式传输数据
- 所有 API 路径以 `/api/v1` 为前缀

## 认证与授权

API 访问需要通过 JWT Token 进行身份验证。除登录接口外，所有接口都需要在请求头中携带有效的 Authorization Token：

```
Authorization: Bearer <token>
```

## 错误处理

API 统一使用以下格式返回错误信息：

```json
{
  "code": 400,
  "message": "错误描述信息",
  "data": null
}
```

常见 HTTP 状态码：
- 200 - 请求成功
- 400 - 请求参数错误
- 401 - 未授权访问
- 404 - 资源不存在
- 500 - 服务器内部错误

## API 列表

### 用户认证相关接口

#### 发送短信验证码
```
POST /api/v1/auth/sms
```
发送短信验证码，用于用户注册或登录。（为简化演示，将验证码通过返回参数返回给用户）

- **请求参数:**

| 参数名   | 类型     | 必填 | 描述   |
|-------|--------|----|------|
| phone | string | 是  | 手机号码 |

- **返回参数:**
```json
{
  "code": 200,
  "data": 2025,
  "message": "发送成功"
}
```

- **状态码说明**：
  - 200 - 发送成功
  - 400 - 参数错误
  - 1001 - 手机号码不存在/格式有误
  - 1002 - 操作频繁

- **状态**：开发中

#### 用户登录
```
POST /api/v1/auth/token
```
用户登录并获取访问令牌。

#### 用户登出
```
DELETE /api/v1/auth/token
```
用户安全退出登录,删除用户登录信息。

### 商品相关接口

#### 获取秒杀商品列表
```
GET /api/v1/products/seckill
```
获取当前正在进行或即将开始的秒杀商品列表。

#### 获取商品详情
```
GET /api/v1/products/{productId}
```
获取指定商品的详细信息。

### 订单相关接口

#### 创建订单
```
POST /api/v1/orders
```
创建一个新的订单。

#### 获取订单详情
```
GET /api/v1/orders/{orderId}
```
获取指定订单的详细信息。

#### 取消订单
```
PUT /api/v1/orders/{orderId}/cancel
```
取消指定的订单。

### 支付相关接口

#### 发起支付
```
POST /api/v1/payments
```
发起一笔支付请求。

#### 查询支付状态
```
GET /api/v1/payments/{paymentId}
```
查询指定支付的当前状态。

## 数据格式

所有请求和响应数据均使用 JSON 格式。日期时间格式统一使用 ISO 8601 标准：
```
YYYY-MM-DDTHH:mm:ss.SSSZ
```

例如：
```
2025-10-09T20:00:00.000+08:00
```

## 分页参数

对于返回列表数据的接口，默认使用以下分页参数：

| 参数名  | 类型      | 必填 | 默认值 | 描述   |
|------|---------|----|-----|------|
| page | integer | 否  | 1   | 页码   |
| size | integer | 否  | 10  | 每页大小 |
| sort | string  | 否  | id  | 排序字段 |

## 版本控制

当前 API 版本为 v1。后续如有重大变更将会发布新版本，同时保留旧版本一段时间以保证平滑过渡。
